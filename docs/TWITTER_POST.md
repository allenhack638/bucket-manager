# Twitter preview draft

Bucket Manager is now on Windows as an open-source preview.

A native S3-compatible browser with the same layout as the macOS app:
- multiple accounts and Windows Credential Manager
- bucket/folder browsing
- transfer queue with pause/resume/cancel
- multipart uploads above 16 MiB
- System/Light/Dark appearance

The Windows installer is unsigned, so SmartScreen may warn. It is a preview,
not a finished 1.0.

Windows 0.1.3: https://github.com/allenhack638/bucket-manager/releases/tag/windows-v0.1.3
macOS 1.0.0: https://github.com/allenhack638/bucket-manager/releases/tag/v1.0.0
